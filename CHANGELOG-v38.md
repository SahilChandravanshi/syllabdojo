# SyllabDojo v38

- Removed the Year date-range option; Analytics now offers Last 12 months, Last month, and Last week.
- Displayed all seven weekday labels on heatmaps.
- Changed daily topic details from an inline dropdown below the calendar to a floating popover over the heatmap. Hovering previews details; clicking pins the popover until closed or another pill is selected.
- Added an Open syllabus shortcut to the right of each exam name above its heatmap. It opens that exam's syllabus tracker in-app.
- Kept the existing monochrome styling and selected-exam synchronization.
