# SyllabDojo v26 UI fixes

- Activity heatmap cells now use grayscale shades matching the Less–More legend, in both light and dark themes.
- Exam dashboard cards now place the exam logo on the left and the exam name, description, total progress, and progress bar together on the right in the same row/container.
- Existing progress data format and syllabus IDs are unchanged.

Run `npm install` and `npm run build` locally before pushing.
