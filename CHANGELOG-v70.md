# v70 — Reset confirmation flow

- Removed the decorative reset/undo icon from the reset dialog header to reduce wasted space.
- Resetting all tracked exams now requires typing the exact phrase `reset all exams progress` in a second confirmation dialog.
- Resetting selected exams now shows a second confirmation dialog listing the exact exam names before proceeding.
- Added cancel/close actions to the confirmation stage; no progress changes until confirmed.
