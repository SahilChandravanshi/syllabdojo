# SyllabDojo v35 — Analytics heatmaps

- Removed analytics summary cards and exam progress bars; analytics now focuses on activity heatmaps.
- Added separate GitHub-style, date/month heatmaps for each selected exam.
- Added an exam selection bar and picker on Analytics using the same selected-exam state as Dashboard.
- Added per-exam activity logging for new topic-completion actions while preserving legacy activity data and existing saved progress.
- Retained the existing monochrome grayscale heatmap palette and theme styling.

Note: historical activity saved before this version was only tracked globally, so it is shown as legacy activity until per-exam history accumulates. New activity is tracked against the exam tracker in which the topic is completed.
